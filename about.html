PBL PROJECT

A decision-support system for technology selection.

TechManager converts a small set of project requirements into a structured technology and delivery plan. The current engine is intentionally explainable and rule-based.

01

Problem

Choosing a suitable stack is difficult when project scope, team size, budget and security needs vary.

02

Solution

The engine maps requirements to a stack, architecture, scalability estimate, security checklist, team roles and roadmap.

03

Technology

Python, Flask, Jinja templates, responsive CSS, JavaScript and SQLite.

04

Future scope

Authentication, PostgreSQL, cloud deployment, ML scoring and generative AI explanations can be added later.
